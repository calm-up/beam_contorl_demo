# J1 四芯片十六通道幅相写后回读统计

只有芯片3/RF2（逻辑通道1）读回 `3A1040`，与写入一致。其余15项低12位均回读为 `000`，不是期望的 `040`。该结果证明当前回读路径可在个别通道读到非零数据，但不能据此确定其余通道零值的根因。
