## 保留什么、清理什么

- 保留 `build/s53`，维持旧工程手动打开、仿真与已有 WDB 的原路径。
- 其他 19 个目录在归档校验和 Git 备份完成后清理。保留其 XPR、综合/实现脚本、报告、日志、自定义仿真源码和 CSV 于 `profiles/`。
- 旧 BIT/LTX/MCS 若与 output 现存文件 SHA256 完全相同，保留现有文件；独有 BIT/LTX、最终检查点、IP XCI、WDB/WCFG 存放在 `output/build_history_artifacts_20261104/`。具体去向见 `manifest.json`。
- 原始 output 中的实测 CSV、结果与交付文件保持原位；大型硬件产物和波形只作本地归档，不上传 Git。
- `manifest.json` 保存清理前目录大小、文件清单、配置、保留文件去向和 SHA256。`*_sources.json` 标识本次归档的 V0.3、S54 源码状态。

## 复盘和恢复边界

原先多个 XPR 都引用共享 `rtl`，现存工程目录没有提供各历史时刻完整独立源码。此次 Git 提交保存的是现存 V0.3 与 S54 源码快照及历史证据，不伪造 S50/S51/S52 的历史提交。历史 BIT 与检查点可以用于当时产物复核，但不保证用当前源码重建出逐位相同的 BIT。

profiles 中的 XPR 是配置证据，仍可能含已清理目录路径。新建工程使用 scripts/create_project.tcl；复核历史参数、ILA 配置时先查看对应 profiles，不能直接用当前默认参数冒充原版本。

清理状态、校验结果和释放空间在完成后补记于本文件及 manifest。
