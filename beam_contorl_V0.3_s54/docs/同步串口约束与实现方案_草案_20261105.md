# 同步串口约束与实现方案

日期为 2026-11-05。本文件用于用户 review，描述拟实现行为。协议新增编号、帧内位序、错误策略和时间候选值属于本次草案设计，需在实现时验证。当前 RTL 尚未实现本文件新增功能。

## 1 已确认的范围

- 外部 SYNC_CLK 为 10 MHz，分配到 FPGA_4。收包后主机持续提供时钟，直到完整收到反馈。
- FPGA 在下降沿接收数据，在上升沿更新反馈。主机在上升沿更新请求，在下降沿采反馈。
- 同步接口新增一颗芯片最多四组幅相码的报文，带 4 位通道掩码。异步调试保留 40。
- 通道使能单独配置。同步幅相批次只更新幅相。
- 一批接收多条报文，校验和 SPI 预写全部成功后回复 READY，由一次外部打入统一装载。
- 外部 T/R 独立响应，高有效作为设计基线，收发互斥。与幅相接收和预写可以并行。
- 当前直接接收移相、衰减码，不引入角度计算。CPI 不参与本方案。
- 芯片 SCLK 保持连续周期运行。LDAC 低电平至少三个芯片 SCLK 周期。

## 2 报文草案

沿用现有外层 AA DD 01 LEN CMD ARRAY PAYLOAD SUM 55。LEN 为总字节数，SUM 为从版本 01 到载荷末字节的累加和低 8 位。同步传输按字节 MSB first，无 UART 起始位和停止位。ARRAY 取 00 为 RX、01 为 TX。

草案用符号 BATCH_BEGIN、CHIP_AP 表示新增命令。具体 CMD 编号在扫描现有 RTL、上位机和文档占用情况后分配，避免复用历史 42/43 的诊断含义。

### 2.1 批次开始帧

| 载荷偏移 | 字段 | 约定 |
|---|---|---|
| 0～1 | BATCH_ID | 16 位，高字节先发，用于应答关联 |
| 2 | FRAME_COUNT | 1～32，本批预期芯片帧数量 |

总长 11 字节。每个波前窗口恰好一个开始帧，且位于首帧。一批限定一个 ARRAY，同一线阵和芯片组合只出现一次。计数表示后续 CHIP_AP 数量，不含开始帧。

### 2.2 芯片幅相帧

| 载荷偏移 | 字段 | 约定 |
|---|---|---|
| 0 | LINE | 0～7，逻辑线阵索引 |
| 1 | CHIP | 0～3，逻辑芯片索引，经现有 CID 映射转换 |
| 2 | CHANNEL_MASK | bit0～bit3 对应逻辑通道 0～3，高四位必须为零，低四位不得全零 |
| 3、4 | PS0、ATT0 | 通道 0 移相、衰减码 |
| 5、6 | PS1、ATT1 | 通道 1 移相、衰减码 |
| 7、8 | PS2、ATT2 | 通道 2 移相、衰减码 |
| 9、10 | PS3、ATT3 | 通道 3 移相、衰减码 |

每帧固定 19 字节。选中通道各码取 0～63，高两位为零。未选中通道字段要求填零，FPGA不执行对应写入。移相码与衰减码继续使用当前码表含义。

通道掩码表示本帧更新哪些幅相，不能用作芯片通道使能。一个芯片帧可更新一至四通道，因此单侧 32 颗芯片最多 32 帧、128 组幅相。

### 2.3 反馈

沿用应答外层，载荷使用 原CMD、STATUS、BATCH_ID_H、BATCH_ID_L、RECEIVED_COUNT，总长 13 字节，10 MHz 下占用 10.4 µs。错误码编号在实现前与现有状态码表统一。

反馈结果包含 READY、帧格式或校验错误、参数错误、帧数不符、重复目标、忙、SPI 执行失败。整批只反馈一次。READY 表示封批通过、目标幅相已完成 SPI 发送、末帧至装载保护时间已满足，允许打入。当前定义不包含逐寄存器 SDO 比较验证，若以后要求芯片回读确认，应增加独立时间预算。

反馈线空闲为高。新反馈从空闲高到首字节 AA 的首位低开始，主机在下降沿搜寻帧头并按 LEN 收完整反馈。首位须在上升沿推出并满足下一下降沿采样预算。反馈开始前至少保留一个完整空闲字节的时钟时间。

## 3 批次与装载规则

波前上升沿开启接收，下降沿封批。接收阶段只缓存，封批时检查预期帧数、逐帧校验、ARRAY 一致、目标唯一及全部参数范围。最后一位到波前下降沿须留出接收及跨域完成余量。

使用 32 位目标位图，索引为 LINE×4+CHIP，检测重复芯片。缓存最多 32 份载荷，容量约 352 字节，另加批次字段和位图。即使帧数达到预期，也等待波前下降沿后才进入 SPI 执行。

建议状态流程为 IDLE → RECEIVE → VALIDATE → PREWRITE → READY → APPLY → IDLE。收到错误的整批不进入 PREWRITE。READY 直到打入或明确复位/取消前保持，禁止新批次覆盖未装载批次。

SPI 预写复用现有幅相帧编码及并行写引擎。按 RF 通道索引组织写入轮次，每轮可在选中线阵的四根 SDI 上分别发送各自的 24 位目标帧，多个线阵也可同轮写入。满配单侧有四个通道索引，在每目标每通道只需一个幅相 SPI 帧的前提下，可组织为四轮。稀疏批次中，同线阵未选芯片仍共享 CSB，须验证其 SDI 所送帧不会修改该芯片，再启用该轮并行写。现有单目标操作的 P1 同帧复制方式保留在原有路径。同步预写抑制逐通道自动 LDAC，最后一轮写完并满足保护间隔后形成 READY。目标线阵掩码由本批帧汇总。

打入仅在 READY 反馈全部发送结束后接受，避免反馈发送中提前消费批次。一次有效上升沿产生一次装载，所有涉及线阵的 LDAC 在同一系统时钟拍拉低，至少保持 600 ns。未涉及线阵保持高。

过早打入不排队补执行，记录错误，主机重新按反馈状态安排打入。重复打入不重复装载。打入时若任一 T/R 有效，拒绝本次装载并保留待装载状态，要求主机在收发关闭期间重新打入。

SPI 执行中失败可能留下部分待装载数据。进入故障状态、禁止打入和后续普通批次，经过复位初始化恢复后才重新接收，避免旧的未装载数据混入后续 LDAC。成功批次的未选通道保持已知的当前配置。该行为需用有影子寄存器和装载寄存器的芯片模型验证。

### 稀疏批次的 SDI 占位

每轮按芯片和 RF 通道检查更新掩码。选中通道发送真实 CID 的写帧。若某根 SDI 在该轮未选中而所在的线阵仍需拉低 CSB，则发送完整的 24 位失配 CID 占位帧。整条线阵本轮无目标时保持 CSB 高。

首选验证候选为现有 41 回读路径用于非目标 SDI 的 `24'hF80000`，其 CID 为 F，读写位为读。启用前核对实际 CID 映射确实不包含 F，并核实芯片协议对该值的处理。现有回读使用记录不能证明它在同步并行写期间是无副作用的空操作，也不能证明失配芯片的 SDO 高阻。

板上验证先给同一线阵四颗芯片设置可区分的基准，再执行稀疏预写并统一 LDAC。逐颗核对目标已更新、未选保持，并检查共享 SDO 是否有额外驱动，覆盖前一事务为回读的情况。占位验证失败时，稀疏轮回退到现有 P1 单目标写法，满配轮仍按独立 SDI 并行。

## 4 通道使能与 T/R

工作前通过独立配置完成芯片通道使能，再进入外部脉冲模式。使能修改要求在收发关闭且同步批次空闲时执行。同步工作期间，异步写入、复位、自动装载等会改变同一芯片状态的操作必须经过资源仲裁，忙时拒绝，避免破坏预写批次。异步 40 的原有调试入口和行为保留。

T/R 模块独立于批次状态机。已有有效配置可在接收下一批及 SPI 预写期间继续工作。首次有效配置未完成时保持关闭，装载和稳定保护期间保持关闭。

外部 T、R 高有效，00 为关闭，10 为发射，01 为接收，11 为同时关闭并记录冲突。两路有效电平采用相同级数同步，输出使用寄存器，并在最终输出端实施互锁。两级同步带来的延迟和相位量化必须纳入对外说明。

110 的接收下降沿后 10 拍发射禁止计数在 50 MHz 下约为 200 ns。本草案建议对两个方向统一实施最少 200 ns 的输出关闭间隔，这是本版新增的对称规则。过早到来的另一路脉冲在关闭间隔结束前被禁止，可能缩短有效输出时间，客户应按规定间隔发送。

有效极性最终依据 FPGA 输入端实测和差分接收器连接核对。110 的发射射频脉宽下限 300 ns 仅作为外部 T/R 输入验证参考，本草案先用两路最短高电平 300 ns 作为候选测试条件，不把该数值视为已经验证的板级接口保证。

## 5 客户时序草案

| 参数 | 草案数值或计算方式 | 状态 |
|---|---|---|
| SYNC_CLK | 10 MHz，周期 100 ns，名义高低各 50 ns | 已确认，最小高低时间与抖动待预算 |
| 波前上升沿到首个数据更新沿 | 至少 2 µs | 草案余量 |
| 最后一位采样到波前下降沿 | 至少 200 ns | 草案余量，需跨域仿真验证 |
| 数据帧间隔 | 支持连续字节、连续帧 | 设计目标 |
| 接收窗口最短高电平 | 2 µs + (11+19N)×0.8 µs + 0.2 µs | N 为 1～32 |
| 满批接收窗口 | 至少 497.4 µs，可暂取 500 µs | 不包含 SPI 预写和反馈 |
| 封批到 READY | 校验处理 + SPI 全批最坏执行时间 + 装载保护 + 反馈排队 | 需 RTL 仿真给出上界 |
| READY 报文发送时间 | 10.4 µs | 13 字节，连续 10 MHz |
| 打入高电平 | 至少 500 ns | 草案，独立于 LDAC 输出宽度 |
| 芯片 SCLK | 5 MHz，周期 200 ns，连续运行 | 当前设计基线 |
| LDAC 低电平 | 至少 600 ns，即 50 MHz 下 30 拍 | 用户要求，当前 RTL 待改 |
| T/R 最短高电平 | 暂按 300 ns 验证 | 候选值 |
| T/R 换向间隔 | 最少 200 ns 的最终输出关闭时间 | 草案，板级核验后冻结 |
| 打入到首次 T/R | FPGA 最坏响应 + LDAC 时序 + 芯片稳定时间 + 裕量 | 待手册、仿真及实测确定 |

协议首位与末位均按采样边沿计算，以上窗口公式包含保守的完整字节周期。主机可以延长窗口，但禁止在预期帧后追加额外帧或非空闲数据。

收包结束后 SYNC_CLK 持续运行，主机等待完整 READY 后安排打入。READY 等待超时必须根据最大批次仿真结果规定，不能沿用异步串口的超时常量。反馈结束后允许停 SYNC_CLK，但下次接收前必须重新提供稳定时钟并满足开窗余量。

600 ns 只是 LDAC 低脉宽。必须核实芯片实际装载生效边沿及建立、保持、稳定时间，才能冻结打入到收发的最小间隔。

## 6 时钟、引脚和 XDC 约束

FPGA_4 对应 U6，属于普通 IO。该信息需与工程器件和当前原理图复核。波前和打入在 B1/B2 的实际对应关系尚待核对，T/R 输入及 RS422 接收、发送引脚沿用板级映射复核结果。

先对 10 MHz 外部时钟驱动串行输入/输出寄存器的路径做独立实现验证。外部时钟域收完整帧后，通过握手和稳定缓存或异步 FIFO 交给系统域。系统域反馈数据先完整锁存，再通过跨域握手交给发送域，禁止跨域直接传单拍 valid，禁止直接读取正在变化的多位总线。

外部时钟可以停止。复位释放、反馈请求和握手必须在时钟恢复后可靠完成，不依赖停钟期间必须取得应答。

若普通 IO 到时钟资源的实现不能满足要求，再评估更快内部时钟过采样方案。不能仅用 CLOCK_DEDICATED_ROUTE FALSE 消除告警作为验收依据。当前 50 MHz 同步、边沿检测后才更新反馈的方案不能直接保证 50 ns 半周期预算。

XDC 应包括以下实际约束，数值以完成的预算为准。

- SYNC_CLK 创建 100 ns 输入时钟并描述波形。
- 请求输入建立上升沿发出、下降沿采样的 min/max input delay。
- 反馈输出建立上升沿发出、主机下降沿采样的 min/max output delay，包含板上接收器、发送器、连线和主机建立保持要求。
- 波前、打入、T/R 作为异步控制输入，仅对同步器入口采用正确的异步路径处理，设置同步寄存器属性。
- 外部时钟域与系统域的例外只覆盖已采用 CDC 结构的路径，配合 report_cdc 检查，避免切断应受约束的数据路径。
- 分别审查 setup、hold、脉宽、时钟路由、跨域和未约束端点报告。

反馈的 50 ns 名义预算需覆盖主机至 FPGA 时钟传播、FPGA 时钟至输出、返回链路和主机建立时间及抖动。请求路径还需预算数据与时钟之间的板级偏斜。预算未闭合前不承诺 10 MHz 已满足。

## 7 RTL 修改边界与验证

新增同步串行收发前端、批次缓存与检查、同步执行及装载控制、外部 T/R 互锁。修改当前写入链路，将幅相预写完成和 LDAC 装载完成分开报告。复用现有 SPI 帧编码、CID 映射、并行写引擎及码表。

先验证独立 10 MHz 路径和引脚，再实现协议缓存、SPI 预写与装载，随后集成 T/R 和异步仲裁。每轮修改提供文件清单、行为变化、验证结果和待用户 review 的差异。

必要验证覆盖以下场景。

1. 单通道掩码、四通道、32 颗芯片满批、RX 和 TX 分别配置。核对同轮各 SDI 的独立帧，并验证共用 CSB 的未选芯片配置保持。
2. 校验错误、半帧封批、少帧、多帧、重复目标、非法掩码、不同 ARRAY 混入均不触发 SPI 或 LDAC。
3. 全部 SPI 写完前不 READY，打入前不 LDAC，打入后目标线阵同时装载至少 600 ns。
4. 芯片模型中待装载幅相与当前有效幅相分开，验证预写期间当前 RF 配置保持，统一打入后才更新。
5. 过早打入、重复打入、反馈未发完打入、T/R 有效时打入、SPI 中途失败和恢复。
6. 波前、打入和 T/R 对系统时钟作相位扫描，10 MHz 请求和反馈作建立保持边界测试，测试停钟及恢复。
7. T/R 同时有效时最终输出互斥，两个方向关闭间隔达标，最短候选脉冲和装载期间门控正确。
8. 异步 40 回归，异步修改与同步批次争用检查。全程芯片 SCLK 的高低宽度与周期无异常停顿。

## 8 本次 review 重点

需要用户重点审阅新增的设计选择，包括每批单侧且目标唯一、批次 16 位 ID、固定 19 字节芯片帧、未选码填零、整批封批后执行、READY 反馈结束才接受打入、T/R 有效时拒绝打入、SPI 失败后复位恢复，以及双向 200 ns 互锁候选值。

实现前仍需工程核验的项目为 CMD/STATUS 编号、波前与打入引脚映射、10 MHz 板级延迟和布线、最坏 SPI 预写时间、芯片 LDAC 生效及稳定时间。上述项目可在实施准备阶段收敛，不能把候选值直接写成已验证的客户保证。
