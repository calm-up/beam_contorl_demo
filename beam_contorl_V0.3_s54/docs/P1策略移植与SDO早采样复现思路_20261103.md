# P1策略移植与SDO早采样复现思路

2026-11-03。本次仅实施P1；未实现新的早采样复现模型，未合入44或装载窗口门控时钟。

## 已实施

- channel_executor：40/C0单芯片操作的通道使能帧、幅相帧，四条SDI均复制目标CID的完整帧（P1）。
- chip_diag_op：42独立写同样使用P1；未选中线阵的SDI置0，CSB仍保持无效。
- 41保持原P2策略（非目标F80000）；20/A0批量路径未修改；43仍是独立LDB。
- 连续时钟、100ns LDB、80ns末位采样及CSB释放时刻不变。
- 修改前快照：snapshots/before_p1_20261103_220704。

验证：主协议完整回归通过TB_V03_PASS，122.297670ms结束。新增逐位监视检查40/C0/42在所有选中线阵的四路SDI一致；覆盖RX7帧、TX2帧，P1_LANE_POLICY_PASS。日志output/s54_p1_protocol.log。验证同时保留原16路连续时钟、24位帧和LDB脉宽检查。未生成新BIT或下载。

## 当前模型的能力

主协议TB使用预设mock_sdo，在有效SCLK下降沿后以延迟赋值输出；适合验证接收与应答，不是厂家完整芯片模型。tb_array_write_sdo已有末位25ns延迟，tb_chip_sdo_pipeline已有上次请求/下一帧响应的简化模型；它们能检验当前接收，但没有“同波形早采必错、晚采恢复”的明确对照结果。

## 后续拟采用的复现方法（未实施）

1. 保持当前SCLK连续200ns周期、CSB边界不变；只在测试侧增加采样观察点，不先修改生产RTL。
2. 用可调的T_CO描述末位从第24个SCLK下降沿到FPGA输入稳定的总延迟。先以25ns演示，再扫描0/10/25/40/60ns，真实值需由芯片资料或板测确定。
3. 选择0C5602作为预期响应，低两位为10：末位稳定前线上仍为1，最终应变成0。
4. 在末次下降沿后20ns取早采样；同一波形在80ns取当前采样。T_CO=25ns时，早采预期得到0C5603，当前采样应为0C5602。
5. 加无延迟对照和反向跳变（低两位01），证明错误来自有效窗口，而非脚本固定篡改最后一位。
6. 波形暴露SCLK、CSB、SDO、末位有效标志、早/当前采样脉冲、两组结果和预期值；断言错误仅为末位、时钟连续、CSB低恰好24位。
7. 然后才考虑接上实际reader/core进行二帧流水复现，进一步纳入经确认的CSB释放/高阻条件。未确认的高阻或LDB内部语义不能当成厂家事实写死。

关键：2C0C08低两位是00，即使最后一位早采也可能相同，不适合作为末位早采的唯一诊断向量。25ns延迟是模拟参数，复现相同错误机制不等于证明实板总延迟恰好25ns。
