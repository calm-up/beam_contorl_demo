# J1 动态幅相零回读排查

2026-10-31，当前板载 s52。

复位后，芯片3/RF2（编码1）与RF1（编码0）分别写衰减索引2、0、3、1，相位均0；8笔写帧均由FPGA引脚ILA核实，读请求及同CID占位帧完整，原始SDO解码与FPGA内部read_value一致。8笔低12位均返回000，非零期望080、0C0、040全部不匹配，零值期望自然匹配。

因此此前芯片3/RF2一次回读040不能作为动态写入有效的结论；可能是旧值或与当时状态有关，尚未证明旧值来源。不能再把它当作稳定通过通道。

复位后抽查四个CID的Control_Reg地址0、RXPS字节地址131、RXATT地址1，共12笔，数据分别04、40、004，全部与初始化期望一致。仅代表这些抽查项，并非再次完成全表验收。

最新写波形中，CSB上升在样点577，LDB下降610，上升660：CSB到LDB间隔33×20ns=660ns；LDB低50×20ns=1us。写帧间CSB高期间包含两个SCLK上升沿。该证据在FPGA侧，不代表芯片管脚电平已测。

当前排除范围：已观察的FPGA输出帧字段错误、把首帧SDO当结果、离线解码与内部寄存器不一致；没有证据表明整个初始化或所有SDO通信失效。仍未定位芯片动态幅相数据为何未按写值返回。

下一组应对照：独立幅相写后、LDB前读取；单独LDB后读取；读请求的数据区填零和填原写值对照；写阶段非目标SDI目前发送各自正确CID的080000/180000/280000/380000读帧，而读阶段用F80000，这一差异也需受控对照。s52无法独立分开写与LDB或指定读请求数据区，需诊断版本支持。现有未构建的42/43诊断入口支持独立写/独立LDB，尚不支持指定读请求数据。
