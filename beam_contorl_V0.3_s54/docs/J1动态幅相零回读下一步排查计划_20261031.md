# J1 动态幅相零回读：下一步排查计划

当前基线：板载 s52；J1 RX；全 16 通道分别写入不同 RX 衰减索引后均读回数据区 `000`。SDI 写帧字段、读请求/占位帧和 FPGA SDO 捕获与 `read_value` 一致，`read_done=1`、`read_error=0`。复位后四颗芯片各抽查控制、RXPS、RXATT 共 12 项通过。此结果支持问题集中在动态幅相写/装载/其回读定义，不等于已定位芯片内部或 LDB。

## 目标与约束

用 J1 逻辑芯片 3、RF2（通道编码 1）作首个对象，所有帧保存 24 位原始值。一次只改变一个因素；每阶段先做 1 次并重复 3 次。发生帧字段错误、超时、错误码或 SDO 全高即停止该阶段并保留数据。只对一个通道操作，其余通道/芯片保持关断。每次初始化只在复位/上电后执行一次，幅相写入前不重刷整套初始表。

期望示例：RX 衰减 1、相位 0 写帧 `321040`；读请求 `3A1000`；同 CID 占位帧 `380000`；若该寄存器按数据手册所理解的方式返回写入值，预期完整响应 `3A1040`。读请求帧期间 SDO 属于上一帧，不能作为此次读结果。

## 阶段 0：冻结、复位和基线

1. 确认阵面供电、J1.20→U9.12→U9.37 SDO 路径和串口空闲状态。
2. 发 RX J1 单线复位，等待 FPGA 报告初始化完成。复位/初始化波形保存，抽查 CID3 的 Control_Reg 地址0、RXPS 地址131、RXATT 地址1，分别期望 `3C0004`、`3D8340`、`3F0404`。
3. 读 CID3/RF2 两次：各发送 `3A1000`、`380000`。保存两帧 SDI、每帧24位引脚 SDO、FPGA `read_value/read_done/read_error`。两次结果须一致；否则先解决读链不稳定，不做后续推断。
4. 此时记录通道开关状态和衰减仪表基线，不执行 RF 功率判断作为数字寄存器结论。

## 阶段 1：分离幅相一级写入与 LDB 装载

需要诊断 BIT。源码已有 debug-only `0x42` 单帧写和 `0x43` 单独 LDB，尚未构建/下载；当前 `0x41` 读固定数据填零。先按继承流程仿真、构建并检查 SPI 配置，再通过 JTAG 下载 BIT，不写 MCS。构建记录要列出源码提交状态、BIT 哈希、ILA probes、Vivado SPI 配置属性。

在 `0x42` 约束下，目标地址/帧应校验 CID3 与写位0。串口数据区按 `0x42` 五字节负载 `{line=0,chip=3,frame[23:16],frame[15:8],frame[7:0]}`。`0x43` 一字节负载 `{line=0}`，阵面字段选择 RX。每条命令均检查协议应答，ILA 同时采集 SDI/CLK/CSB/LDB、SCLK 帧间上升沿及 SDO。

执行次序：

1. 读基线 `3A1000 → 380000`。
2. 只写 `321040`（`0x42`），不发 LDB；立刻读 `3A1000 → 380000`。记录返回值，不预设一级寄存器是否可通过功能2读到。
3. 单独发 `0x43` LDB；再读同一通道。比较 LDB 前后返回值。
4. 只写不同值 `321080`，不发 LDB；读一次；单独 LDB；再读一次。
5. 每个组合重复3次，并在每次写前记录实际旧值。只有读值随写入 040→080 可重复变化，才能确认 SPI 写数据进入可读寄存器；只有 LDB 前后差异可重复，才能把影响归到装载边沿。

判读：

| 观察 | 可支持的结论 | 后续动作 |
|---|---|---|
| 写后（LDB前）跟随值变化，LDB后仍相同 | 写与读链有响应；读回可能观察一级寄存器，LDB是否改变当前读值尚不能定性 | 继续确认二级寄存器定义及RF响应 |
| 写后不变，LDB后才跟随变化 | LDB参与读可见值更新 | 检查 LDB 到芯片管脚的时序/电平，再测 RF |
| 写后、LDB后均不变 | 不能区分写帧未被芯片接收与功能2读语义不同 | 进入阶段2，用厂家定义帧或芯片端波形分离 |
| 返回头/地址变化或 SDO 全高 | 目标寻址、SDO路径或流水有问题 | 暂停幅相结论，先修读链 |

## 阶段 2：受控核对读帧规则和共享 SDO

不得把非目标芯片的策略当手册保证。现有正常 `0x40` 写流程中，非目标 SDI 收到各自正确 CID 的读/空操作帧；读 `0x41` 时非目标 SDI 发 `F80000`。两个阶段策略不同。单独实现可配置非目标 SDI 帧的诊断操作，但每次只切换一种策略，并核对 SDO 是否多源驱动。

另外，手册称有效读命令后的下一帧仍会生效；“正确 CID、读写位为1、其余字段填0/1”的无效帧示例与现有 `CID8_0000` 的具体解释需向芯片厂家核实。不要假定读帧数据区会写入，也不要在未核实前把原始写值填回读请求并据此宣称正确。若要比较读命令数据区，扩展一个仅改变请求/后续帧数据填充值的诊断版本，保留相同 CID、功能、通道、时钟和占位帧，并显式跟踪三帧流水；分别验证首帧请求的响应对应哪一帧 SDO。

## 阶段 3：确认芯片端信号和 RF

1. 用示波器量 J1.24 LDB、J1 CLK、J1 CSB；记录 CSB上升→LDB下降、LDB低脉宽、CSB高期间两个SCLK上升沿。当前已有 J1.24 约 1 µs、3.3/0 V 的用户测量和 FPGA ILA 660 ns 保护间隔；重测时检查目标实际事务，不能用旧波形代替。
2. 芯片管脚不可测时，只报告 J1连接器证据；不能据此声称芯片焊盘已接收。
3. 数字写/读关系稳定后，才保持连续波和频谱仪设置不变，比较 RF2 衰减索引0/1/2/31，每档等待读数稳定并记录 Marker 和波动范围；此前全通道测试的返回数据区全零，因此原 RF 衰减对比不作为数字写成功证据。

## 阶段 4：扩展复测

单通道根因闭合后，再用每通道唯一值重复 J1 16 通道。每项保留写入、请求、占位、SDO响应和内部读值；目标CID、函数、通道、数据四段分别比较。之后至少做3次复位/初始化循环。只有所有目标数据匹配，才统计动态幅相数字寄存器通过；RF衰减/移相仍单独验收。

## 需要修改/保留的证据

- `0x42/0x43` 目前只存在 RTL 源码，需增加联合仿真，确认无LDB写、单独LDB、对错误CID拒绝及完成握手。
- 新增后续帧可控读操作前，需先确认3帧流水和SDO采样关联；不要只比较 `read_value`，需从引脚波形独立解码。
- 每步归档 UART 原始 TX/RX、协议应答、全24位引脚帧、FPGA `read_value`、ILA时序、频谱读数、BIT SHA-256。失败项不重试覆盖原始文件。
