# V0.3 按 110 对齐的更新与验证清单

日期：2026-10-23。实施目标：同步更新协议、FPGA RTL、Qt；测试修改后协议的每个命令。参考原 110 的命令含义和 Flash 分层，板级帧、阵面地址和 CCAR10405L 时序按本项目硬件适配。

## 用户确定的变更

1. 删除 `D0`。不增加 `41` 或其他预装载命令；每条控制命令完成其自身写入和生效后应答。
2. `C0` 按 110 的“选中位置写入、其他位置保持”执行，不对旧幅相作有符号加减。
3. 脉冲形式参考 110 的模式类别和时序；FPGA 对 CCAR10405L 的 T/R 输出必须满足本芯片真值表，不直接照搬 110 旧板电平。缺外部同步输入的模式不得假装已执行。
4. `F1/F2` 恢复 110 的普通记录和 `11/12/13` 专用记录分类语义，不把普通记录强制编码为新增的 `00` 类别；外层 V0.3 帧仍适配收/发独立阵面。
5. 衰减码按 110 的原字段保留 6 位数据；CCAR10405L 主手册给出0～31.5dB、0.5dB步进，配套SPI表只列到15.5dB，两份资料冲突须保留验证记录。暂不把 0～31 当作已证实的硬件极限。
6. STC、窗函数、串/并口衰减等字段按 110 保留。若当前板上没有对应执行器，必须在命令级清楚报告实际支持范围，不能对未执行字段回成功。

## 必须如实标识的未确认资料

- 四颗芯片实际 CID 接法、芯内通道与射频口映射。
- 本项目阵元坐标/间距和发、收独立角度模型；第一版按用户要求先复用已数值验证的 110 计算源码，但不能称为本板射频校准结果。
- 配套 SPI 文件要求的器件初始化寄存器表；当前没有可用于确认全部上电初始化值的完整表。
- U22 实装型号和 JEDEC ID、写保护状态；写入前必须先读 ID 和状态。
- 外部脉冲输入时序。无该输入时，外部同步模式只能明确返回不支持。

## 本轮验证结果与剩余差异

- 自动仿真覆盖 `00/40/C0/E0/F1/F2/F3/F5`，包括 F2 重复写入拒绝、F1 同扇区其他记录被清除、F3 有效记录计数、F5 分区擦除、坏校验和丢弃、删除后的 D0 拒绝，以及 `20/A0` 未实现应答。独立仿真覆盖 110 脉冲计数、收发互斥和 U22 底层写使能/页写/擦除/读回。Qt 协议单测遍历 16 种保留模式，界面冒烟测试通过。以上为模拟器验证，不能代替接收 J1 阵面和 U22 的板级测量。
- 110 原工程的角度计算源码和系数文件已保存并独立数值核验；当前缺少本项目阵元坐标、阵元间距、发/收方向定义、Ku 频率到频点索引关系以及通道至物理阵元映射。直接使用旧 X 波段常数会生成错误幅相，故 `20/A0` 暂回 `05`。这两条是尚未完成的功能，不能计入已验证指令。
- 本项目外层帧采用 V0.3 长度和累加和，保留独立接收/发射阵面和 CCAR10405L 的 24 位写入；110 固定 17 字节/XOR 帧与原阵列几何不能直接复用。F1/F2 数据区按 110 位置保留，U22 分区按本项目 128 通道/阵面扩展；暂用 0～31 频点序号，不能当作实际 Ku 频率。D0 依用户决定删除。F1/F2 增加空白检查、JEDEC ID 限制和写后读回；F5 按所选阵面逐扇区擦除，不执行整片擦除。F3 当前重建缓存，不自动更新阵面。
- Vivado 2022.2 的隔离 `review` 构建已完成布线并生成 BIT：`output/review/beam_control_v03_review.bit`。50 MHz 约束下，建立时间余量 7.681 ns、保持时间余量 0.035 ns，均无失败端点。实现使用 7 个 RAMB36、1 个 RAMB18。DRC 0 错误、1 条 `PLCK-12` 警告，原因仍是板载时钟在 V20 的 N 侧且采用临时非专用 IBUF→BUFG 路由。尚未建立外部接口输入/输出延迟约束，不能据此宣称板级时序已经闭合。
